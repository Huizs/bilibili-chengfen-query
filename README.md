# B站成分查询 (bilibili-chengfen-query)
> 油猴脚本，在B站评论区楼层添加查询按钮，提取用户公开资料做关键词匹配统计。所有计算、规则存储均在本地浏览器执行，**与 B站 无任何官方关联**。

## ✨ 功能特性
- 在评论区用户名旁添加 🔍 查询按钮，点击即可查询单用户；
- 可开启视口内自动扫描：进入可视区域的评论才执行查询，有并发上限，查询结果按UID本地缓存；
- 适配视频页、动态页、专栏、直播间等B站页面；
- 信息面板：展示用户资料、关键词命中记录、命中来源、粉丝勋章与账号关注匹配信息；
- 自定义规则面板：支持新增/修改/删除匹配规则，支持规则导入、导出、恢复默认。

## 🚀 安装
1. 浏览器安装 Tampermonkey（油猴）扩展；
2. 油猴面板 → 添加新脚本，粘贴脚本完整代码并保存；

## 🧠 匹配口径
语料来源：用户公开空间动态、昵称、签名、个人简介。
- `★`：用户本人直接发布内容（动态正文、简介等）
- `·`：卡片附属内容（视频标题、转发内容等）

规则语法：`|` 或、`&` 与、`!` 前缀排除。
匹配强度按关键词命中次数分级，命中记录附带原文跳转链接。
勋章、官方账号关注仅作为补充佐证；关注列表、勋章墙存在隐私隐藏情况，无法作为否定结论依据。

## 🔒 数据与隐私

- 规则配置、界面设置长期保存在浏览器本地；
- 用户接口返回的动态原文仅保留在内存，页面刷新即清空，不会持久写入本地磁盘；
- 不存在任何服务端数据上报，所有计算都在你的浏览器本地运行，项目作者无法获取你的查询记录；
- 所有网络请求由**使用者自己浏览器、自己登录会话**发出。
- 脚本调用第三方公开接口，第三方服务可用性不受本项目控制。
